2026.08.0

Released: 6.8.2026

First complete version with data from both FWF and FFG and a projects network diagram.
The admin interface allow for creation of configurations for required technologies and pipelines to gather data from FFG and FWF, as well as a data refinement pipeline, that combines the data and transforms it for the dashboard.
The dashboard gives an overview of all configured technologies and shows network graphs for all projects with associated organisation for every specific technology field.
